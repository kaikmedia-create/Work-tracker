# Relief Studio 28 — vereinfachte Benutzeroberfläche
**Stand:** 16. November 2026

- Eingabefelder für Kartenausschnittbreite/-höhe in Kilometern und Breiten-/Längengrad entfernt. Der Ausschnitt wird weiterhin per Ziehen und Eckgriffen verändert.
- Genannte Fließtexte über Gelände, amtliche Flächen, Messpunkte, 3DBAG, Overture und Dachschätzungen sowie manuelle amtliche Import- und Aktualisierungsbuttons aus dem Editor entfernt. Quellen und Datenqualitätsinformationen bleiben im Quellenexport bzw. in Diagnose- und Quelldaten verfügbar.
- Weltweiter Gebäudequellenabgleich wird beim Erstellen jeder 3D-Karte automatisch ausgelöst, auch wenn ältere gespeicherte Einstellungen ihn deaktiviert hatten.
- Einstellungsleiste links kann auf Desktop ein- und ausgeklappt werden; der Modell-Viewer füllt die freie Breite. Tastatur und mobile Oberflächen bleiben berücksichtigt.
- Der technische PIN-Hinweis wurde aus dem Editor entfernt. Die relevante Warnung vor unsicherem serverseitigem Schutz bleibt auf der Login-Seite sichtbar.
- UI-Patch wird sowohl auf die lokale, versionsgeprüfte Quellcode-Materialisierung als auch auf die verschlüsselte GitHub-Pages-Vorschau angewendet.
