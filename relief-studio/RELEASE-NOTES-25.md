# Relief Studio 25 – senkrechte Gebäudenaht

Trifft eine lange Wandkante im exportierbaren Koordinatensystem genau auf eine vollständige, entgegengesetzt orientierte Kette kürzerer Kanten, verwendet auch die gegenüberliegende Wand deren vorhandene Zwischenpunkte. Die Wand bleibt an derselben Stelle. Echte Lücken werden nicht überdeckt. Nach einer Teilung prüft das Studio das gesamte Netz erneut; ein fehlerhaftes Modell bleibt für den Export gesperrt.
